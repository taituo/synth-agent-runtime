# Process archive

Working documents from the project's coordination: review rounds, plans, role briefs and task
specs. They lived in `/tmp` for months, which does not survive a reboot — and
`STANDING-ORDERS.md` in this very directory says that anything here that matters permanently
belongs in the repository. Nobody had done it. This is that, before a machine was destroyed and
the question "do we lose anything?" made the exposure obvious.

Read these as a record of how the work was done, not as current documentation. Current
architecture is `docs/DIRECTION.md`; current capabilities are `README-REALITY.md` and
`README-REALITY-INSIDER.md`.

The most valuable single file is `review-findings.md` — seven rounds of adversarial review,
including the four occasions the gym scorer was forged. `reality-check.md` is an outside
assessment of the whole project. `STANDING-ORDERS.md` holds the rules that were learned by
getting them wrong.

Host addresses and key filenames are redacted; private cluster addresses are kept because they
carry meaning and reach nothing.
